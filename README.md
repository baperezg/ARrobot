AR Robot Visualization (Unity + Vuforia)

This project is a mobile augmented reality application built with Unity 6000.6.11f1 and Vuforia Engine 11.4.4. It allows users to visualize and interact with a mobile robot in AR using an Android device.

Key features:

📱 AR Visualization: Overlay a 3D robot model on real-world surfaces using Vuforia ground plane.
🎮 Interactive UI: On‑screen buttons for movement (forward/backward) and rotation (clockwise/counter‑clockwise).
⚙️ Android Build: Optimized for Android 11+ devices with portrait UI layout.
🧩 Educational Tool: Designed for robotics and AR learning, simulation, and demonstration.
